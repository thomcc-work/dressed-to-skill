# Consolidating instructions

Compare required behavior and conditions before calling two policies duplicates.
“Prioritize clarity → precision → concision” ranks goals; “Use concise, clear language” directs writing style.
Keep both, though they can appear together.

When policies do duplicate each other, keep one authoritative definition with direct links from the pages where readers start the affected tasks.
Usually keep those distinct ways to find the definition; test each starting page before removing a link.
A link must say why the reader needs it, not merely “See testing.md.”
Preserve useful links from a task's starting page to the page that defines its procedure, then to a specific topic.
If a required rule takes more than three links to reach, shorten that path or state the needed constraint beside the action it governs.

Keep a repeated safety constraint at the point of action when its absence permits a concrete misunderstanding or unsafe action.
Otherwise, test deletion or a direct reference rather than preserving text solely because it existed.
